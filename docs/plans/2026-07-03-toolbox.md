# Инструменты для генератора 3D-бейджей

Все инструменты — бесплатные, open-source, работают в браузере без ключей
(кроме фотостоков, где ключ бесплатный). Проверено 2026-07-03.

## Локальный ИИ в браузере («дизайн-мозг»)

| Инструмент | Зачем |
| --- | --- |
| **transformers.js** (huggingface) | CLIP локально: смысловой отбор фото под запрос, отсев мусора; zero-shot классификация «интерьер/пейзаж/люди». WebGPU — до 100× быстрее WASM. Модели кешируются. |
| **onnxruntime-web** | Низкоуровневый ONNX-рантайм — если понадобится своя модель вне transformers.js. |
| **@imgly/background-removal** | Вырезание объекта из фото (факел, стадион, самолёт) — нейросеть в браузере, WASM. |
| **MediaPipe Tasks Vision** (Google) | Альтернатива/дополнение: interactive segmenter (клик по объекту → маска), сегментация по категориям. |
| **smartcrop.js** | Умный кроп: находит композиционно важную зону фото (края, насыщенность) — автоцентрирование фона под форму бейджа. |
| **UpscalerJS** | AI-апскейл/денойз мелких кадров из Wikimedia (частая проблема — хорошие, но маленькие фото). |

## Векторная графика, текст, деформации

| Инструмент | Зачем |
| --- | --- |
| **opentype.js** | Текст → SVG-path (глифы как кривые). База для 3D-экструзии, warp-текста, текста по дуге с точным контролем. |
| **warp.js (benjamminf/warpjs)** | Envelope distort SVG-путей: волновая деформация флагов/лент и warp текста (арки, флаги, выпуклости — как Illustrator Envelope). |
| **flubber** | Плавная интерполяция между SVG-путями (морфинг форм лент/изгибов). |
| **svg-path-properties / svgpath** | Математика путей: длины, точки, трансформации — для нарезки флага на полосы вдоль волны. |
| **fontsource** | Самохостинг всех дисплейных шрифтов (уже в проекте: Manrope, Oswald). |

## Обработка изображений (арт-стиль, палитры)

| Инструмент | Зачем |
| --- | --- |
| **image-q** | Цветовая квантизация (posterize) — ядро арт-стиля «фото → иллюстрация». |
| **imagetracerjs** | Растр → векторные пятна (SVG) — «иллюстративный» фон из фото, чистые плоские формы. |
| **node-vibrant** (браузерная сборка) | Извлечение палитры из фото (Vibrant/Muted/Dark…) — автоподбор цветов рамки/лент/акцентов. |
| **culori** | Цветовая математика: LAB/OKLCH, гармонизация вклеенного объекта под фон, контраст текста. |
| **StackBlur / canvas filter** | Быстрое размытие зон (низ фото под текст, глубина резкости). |
| **pica** | Высококачественный ресайз на canvas (даунскейл 800→200 лучше нативного). |

## 3D и рендер

| Инструмент | Зачем |
| --- | --- |
| **three.js** | Этап 4: лента-ткань с волной и освещением, металлическая рамка, экструзия текста (TextGeometry + bevel). Offscreen-рендер в слой. |
| **troika-three-text** | Качественный текст в three.js (SDF), если TextGeometry не хватит. |
| **html-to-image** | Экспорт (уже в проекте, отлажен). |

## Источники контента

| Источник | Зачем |
| --- | --- |
| **Pexels API** | Основной фотосток (бесплатный ключ, 200 req/h, хотлинк ок). |
| **Unsplash API** | Второй сток (бесплатный ключ, 50 req/h demo). |
| **Wikimedia Commons API** | Без ключа; точечные достопримечательности через категории (уже интегрирован в badge-режиме). |
| **Pixabay API** | Бесплатный ключ, 100 req/мин, 1.9M фото+векторы+иллюстрации (иллюстрации — готовый материал для арт-стиля). |
| **Openverse API** | Без ключа; агрегатор открытых лицензий (Flickr CC, музеи) — широта охвата. |
| **Wikimedia geosearch** | Без ключа; фото в радиусе от координат (аэропорт/центр города) — находит виды, о которых текстовый поиск не знает. |
| **Wikidata SPARQL** | Без ключа; база знаний: город → его достопримечательности (стадионы, канатки, набережные) с готовым фото (P18) и координатами. Ядро ассоциативных цепочек. |
| **OSM Overpass API** | Без ключа; POI вокруг города (tourism=attraction, aeroway=terminal) — второй источник ассоциаций. |

Отпало: **Flickr API** — с 2025 ключи только для Pro-подписчиков.
| **flag-icons + flagcdn** | Векторные флаги ~250 стран (уже в проекте). |
| **airports-data** | ICAO → город/страна (уже в проекте). |

## Что осознанно НЕ берём

- **fabric.js / konva** — канвас-редакторы общего назначения; наш SVG-стек
  слоёв уже делает то же и остаётся векторным до экспорта.
- **CamanJS, glfx.js** — заброшены; их эффекты покрываются canvas
  filter + image-q.
- Любые платные AI API — по требованиям проекта.

## Порядок подключения по этапам

- Этап 2 (поиск фонов): Pexels/Unsplash/Openverse + smartcrop.js.
- Этап 3 (ленты/текст/арт): opentype.js, warp.js, svgpath, image-q,
  imagetracerjs, node-vibrant, culori, fontsource-шрифты, pica.
- Этап 3.5 (авто-Photoshop): @imgly/background-removal (или MediaPipe),
  UpscalerJS.
- Этап 4: three.js (+troika при необходимости).
- Этап 5 (мозг): transformers.js (CLIP) + всё выше.
