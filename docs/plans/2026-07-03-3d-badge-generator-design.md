# Дизайн: генератор 3D-бейджей (200×200)

Дата: 2026-07-03. Статус: утверждён.

## Цель

Новый режим «3D-бейдж» в BannerGenerator: многослойные объёмные бейджи ивентов
уровня AI-примеров (развевающиеся ленты, металл, глубина), с подбором фоновых
фотографий под конкретное место ивента. На выходе пользователь скачивает
готовый PNG 200×200. Инструмент общий — для стаффа разных виртуальных
авиакомпаний; первичное тестирование своим проектом.

Ограничение: без платных API и AI-генерации. Только бесплатные фотостоки.
Существующие баннеры и логотипы Nordwind/RAG не трогаем.

## Архитектура

Основной рендер — SVG (как в текущем генераторе), экспорт через html-to-image:
рендер в 800×800 → даунскейл до 200×200 для чёткости. Отдельный режим
Three.js поставляет фотореалистичные слои (лента, рамка) как offscreen-canvas
картинки внутрь того же SVG-стека — не заменяет пайплайн, а дополняет.

### Стек слоёв (снизу вверх)

1. **Фото-фон** — кадр со стока или загруженный, обрезан по форме бейджа.
   Пан/зум мышью на превью, яркость/контраст/насыщенность, градиентное
   затемнение снизу под текст.
2. **2D арт-объекты** — существующие фигуры (горы, море, здания) поверх фото,
   прозрачность и режим наложения.
3. **Объёмная рамка** — металл (золото/серебро/бронза), эмаль в цвет ВА,
   шлифованный металл, карбон, стекло/хрусталь. Bevel через SVG-фильтры
   (feSpecularLighting, внутренние тени, блик-дуга). Рифлёный край как опция.
4. **3D-лента** — развевающаяся, с текстом по кривой.
5. **Верхний слой** — логотип ВА, иконки, даты.

### Формы бейджа

Круг, щит (варианты), шестигранник, розетка с рифлением, звезда, ромб,
медаль с ушком и орденской колодкой, щит с крыльями по бокам.

## Поиск фоновых фотографий

Источники (объединяются в одну ленту результатов):
- **Pexels** — основной (бесплатный ключ, 200 req/h, хотлинк разрешён);
- **Unsplash** — второй (бесплатный ключ, 50 req/h demo);
- **Wikimedia Commons** — без ключа; точечные объекты через категории
  («Category:Sochi Olympic Park») — стоки таких мест не знают.

Ключи: `.env` для своей сборки + поле «свой ключ» в настройках UI
(localStorage) + бесключевой Wikimedia как фолбэк.

UX: панель «Фон» → вкладки «Поиск фото» (строка + сетка превью, бесконечная
прокрутка) и «Загрузить своё» (drag&drop). Для города из базы аэропортов —
**чипы локаций** с заготовленными английскими запросами: Сочи → «Аэропорт»,
«Олимпийский парк», «Красная Поляна», «Набережная на закате», «Морской порт»,
«Отели». База: `src/data/cityBackdrops.ts`, старт — топ-20 городов маршрутов.
Атрибуция автора — копируемая строка под выбранным фото.

### Фильтрация релевантности (без интерьеров и мусора)

- обогащение запроса: `landmark / cityscape / aerial view / exterior`;
- стоп-лист по тегам/alt: interior, indoor, room, office, wall, table,
  person, portrait, food… (редактируется в cityBackdrops.ts);
- только `orientation=landscape`, разрешение ≥1600px;
- Wikimedia — поиск по категориям, а не по тексту;
- чипы-запросы вручную проверяются на реальной выдаче при реализации.

## Ленты (ribbon)

SVG-библиотека из 6–8 форм с запечёнными складками/тенями (многослойные
градиенты), 2 перекрашиваемые зоны (лицо + изнанка, изнанка автоматически
темнее на 25%), текст по кривой (textPath) с автоподбором размера,
2–3 варианта изгиба на форму.

Позиции: снизу по центру, дуга сверху, диагональ в углу, **зеркально по
обоим краям** (текст может делиться: город слева / год справа), **одиночная
слева**, **одиночная справа** (с перегибом «за рамку»: верх ленты поверх
рамки, хвост под ней).

### Флаговые ленты и развевающиеся флаги

Заливка ленты: цвет ВА / свой цвет / любой из ~250 флагов (flag-icons).
Флаг должен развеваться, а не лежать плоской наклейкой:

- **SVG — деформация нарезкой**: флаг режется на 20–30 вертикальных полос,
  каждая трансформируется вдоль волновой кривой Безье (сдвиг + наклон +
  сжатие на изгибах); поверх — слой света/тени по той же кривой (гребень
  светлее, впадина темнее). Параметры: амплитуда, число волн (1–3),
  направление. Работает с любым флагом автоматически.
- **Three.js**: флаг — текстура на ткани с синусоидальной деформацией и
  освещением.

Развевающийся флаг доступен и как самостоятельный элемент бейджа.
Флаг подставляется автоматически из страны города ивента, можно сменить.

## 3D-текст и шрифты

- Экструзия с фаской: SVG — многослойные смещённые копии с градиентным
  «торцом»; Three.js — TextGeometry с bevel и материалами.
- Материалы текста: золото, хром, эмаль с обводкой, неон со свечением,
  гравировка (вдавленный), тиснение.
- Библиотека ~10 дисплейных шрифтов с кириллицей (Bebas Neue, Russo One,
  Cinzel, Oswald, Black Ops One…), у каждого готовый 3D-пресет.

## Размещения текста

На ленте; по кругу внутри рамки (как на монете); дуги сверху и снизу;
металлическая табличка-плашка; вертикально сбоку; крупный полупрозрачный
год фоном; капсула дат под бейджем.

## Декор

Лавровые ветви, звёзды по ободу, заклёпки, роза ветров, крылья пилота,
самолётный силуэт по дуге.

## Темы-пресеты

5 связок рамка+лента+шрифт+тонировка одним кликом: «Горы», «Море/закат»,
«Ночной город», «Олимпийский», «Ретро-авиа».

## Этапы реализации

1. **Фундамент**: режим «3D-бейдж», стек слоёв, формы, кроп фото с
   пан/зумом, загрузка своего фона, экспорт 200×200 (через 800×800).
2. **Поиск фонов**: Pexels + Unsplash + Wikimedia, фильтры релевантности,
   чипы локаций, поле своего ключа, атрибуция.
3. **SVG-ленты, флаги, рамка, 3D-текст**: библиотека лент со всеми
   позициями, флаговая деформация, материалы рамки, экструзия текста,
   размещения текста, декор, темы-пресеты.
4. **Three.js-режим**: реалистичные лента/флаг/рамка/текст с освещением
   как альтернативный рендер слоёв.

Каждый этап — рабочий результат; проверка Playwright-скриншотами.
